# Send by GroupChatOn

https://send.groupchaton.com: send files and notes directly between two devices with a one-time code. WebRTC (always encrypted), nothing uploaded or stored, no sign-up.

- `src/assets/send.js`: the transfer app (pairing via PeerJS, accept-first transfers, safety code).
- `scripts/build.py`: builds every page into `docs/` (served by GitHub Pages). `python -X utf8 scripts/build.py`
- `scripts/brand.py`: makes the logo and icons in `static/brand/`.
