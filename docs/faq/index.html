Send: questions and answers

Everything people ask about sending files directly between devices with Send.

Is Send really free?

Yes. There is no sign-up, no plan and no limit on the number of files. Send costs almost nothing to run because your files never touch our servers.

Is there a file size limit?

No limit is set by Send. Very large files (several GB) work best in Chrome or Edge on a computer, which save them straight to disk. Phones keep a received file in memory until you tap Save, so a phone may struggle with files bigger than 1 to 2 GB.

Do both devices need to be online at the same time?

Yes. Send moves the file live from one device to the other, so both keep the page open until the transfer ends. Nothing is kept for later.

Can someone else join with my code?

A code works for one connection only and is random (about a trillion possibilities). The moment two devices pair, both leave the pairing service, so the code stops working. Even then, nothing reaches you until you tap Accept.

What is the safety code?

Four small pictures made from the encryption keys of this connection. If both screens show the same four, the two devices are talking straight to each other with nobody in the middle.

Does it work between a phone and a computer, or across countries?

Yes. Any two devices with an up-to-date browser and internet work: Android, iPhone, Windows, Mac, Linux, Chromebook. Distance doesn't matter.

Does Send keep a copy of my files?

No. Files go from one device to the other and are never uploaded. There is nowhere for a copy to be.

Why didn't the devices connect?

Some office, school and public networks block direct connections. Send tells you after about 25 seconds. Switch one of the devices to mobile data or to a different Wi-Fi, tap New code, and try again.

I accepted a file but it says "not saved yet". Where is it?

It is ready inside the page. Tap Save next to it and your browser saves it to Downloads (on iPhone, choose where to save in the box that opens).

Can I send to several people at once?

Not yet. One code pairs exactly two devices. To send to another person, finish, then pair again with a new code.

Can I send folders?

Choose all the files inside the folder (or zip the folder first). Several files can be sent in one go; they move one after another.

Does it use my mobile data?

Yes, if you are on mobile data: the file travels over the internet like any download. On the same Wi-Fi, many routers send it locally, which is faster.

Which browsers work?

Current versions of Chrome, Edge, Firefox, Safari, Samsung Internet and Opera, on phones and computers.

Can I install it?

Yes. Use the install button in the header (or Share → Add to Home Screen on iPhone). It opens in its own window like an app.

Is there a limit on notes?

A note can be up to 20,000 characters, enough for long messages, links or a list of passwords you don't want to put in a chat app.
